# Loja Natal Coité 2026 — Sigma Lab 3D

Vitrine online das peças personalizadas de Natal (Igreja Matriz de Conceição do Coité), com carrinho
e pedido enviado pelo WhatsApp. Página estática: `index.html` + `img/`.

Gerada por `comum/gerar_loja.py` (kit Natal Coité). Para atualizar textos, preços e opções, edite
`comum/catalogo.json`, rode o gerador e faça push: o Railway publica de novo.
